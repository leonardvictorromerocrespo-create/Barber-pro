# Recurso visual de la portada MERYO

## Logotipo

- `public/meryo-logo.png` se deriva del logo entregado por el usuario el 29 de octubre de 2026.
- Se retiró el fondo blanco y se recortó el lienzo transparente; la geometría, tipografía y cortes se conservaron. El lettering negro se adaptó a blanco cálido para el fondo carbón y el oro se tomó del color dominante del archivo entregado (`#c79818`).
- La animación de entrada revela el primer 23 % del logotipo, donde está la M, y después completa la palabra.
